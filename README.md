# tutors-ui

Friendly React component library for the Tutors app: Button, Input, Card, Badge, Avatar, Alert, Tabs and Modal.

```sh
npm install
npm run storybook   # browse the components on :6006
npm run build       # build dist/
```

Import the stylesheet once, then use the components:

```tsx
import 'tutors-ui/styles.css';
import { Button } from 'tutors-ui';
```
